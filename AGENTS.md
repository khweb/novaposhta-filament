# Правила пакета «API Нова Пошта»

- Джерело вимог: `docs/implementation-plan.md`. Узгоджені зміни відображайте в плані.
- Для пошуку коду спочатку використовуйте codebase-memory: list_projects/index_status, search_graph, trace_path, get_code_snippet. Викликайте check_index_coverage для використаних файлів; прогалини перевіряйте читанням джерел. Якщо граф недоступний, повідомте про це та використовуйте вихідний код.
- Сумісність: Filament ^5.11, Livewire ^4.0, Laravel ^12.0|^13.0. Це самостійний Composer-пакет без демонстраційного застосунку.
- Використовуйте навички laravel-specialist, laravel-patterns, laravel-filament, laravel-filament-v5, olakunlevpn-filament-skills, laravel-filament-v5-ui-ux, UI UX Pro Max та офіційний livewire-development v4. Недоступні навички шукайте; обмеження фіксуйте.
- Бізнес-логіка, HTTP-адаптер, синхронізація та пошук розміщуються в сервісах. UI та REST використовують ці сервіси.
- Усі таблиці використовують єдиний налаштовуваний префікс; префікс з’єднання Laravel не додавайте вручну. Префікс задається до міграцій; зміна конфігурації не перейменовує дані. Міграції мають підтримувати rollback, SQLite, MySQL і PostgreSQL.
- Ключ шифруйте в БД; не повертайте його в Livewire, відповіді й журнали. Адміністративні дії перевіряють Gates; за замовчуванням доступ закритий.
- Тексти інтерфейсу перекладайте на uk, ru та en із резервною uk. Зберігайте стандартну тему Filament, доступність і адаптивність.
- Оновлення виконуються в черзі під спільним блокуванням і атомарно публікують повністю перевірене покоління. Помилка зберігає попередні дані. Журнали не містять секретів.
- Обов’язкові перевірки: PHP syntax, HTTP fixtures, префікси/rollback, Gates/захист ключа, пагінація/повнота, конкурентність/збої поколінь, розклад, REST/ліміти й Livewire. Реальні API та браузерні перевірки виконуйте за наявності середовища; невиконані перевірки не позначайте успішними.
- Публічну документацію, issues і pull requests оформлюйте українською. Бейджі мають відображати підтверджені вимоги; не заявляйте неіснуючі релізи, публікацію на Packagist чи успішний GitHub CI.
- Під «агентами» мається на увазі цей файл. Не запускайте паралельних виконавців і не створюйте файли ролей.
