# Повідомлення про вразливості

Якщо ви виявили витік API-ключа, обхід авторизації або іншу вразливість, повідомте про неї приватно.

У GitHub-репозиторії використовуйте **Security → Advisories → Report a vulnerability**, якщо приватні повідомлення ввімкнено. Якщо ця можливість недоступна, зв’яжіться з власником репозиторію через контакт, який він указав у своєму профілі.

Не додавайте до публічних issues API-ключі, `APP_KEY`, вміст `.env` чи дані контрагентів. Для відтворення використовуйте тестові значення та знеособлені приклади.

У повідомленні вкажіть:

- версію пакета або commit;
- версії PHP, Laravel, Filament і Livewire;
- кроки відтворення та можливий вплив;
- мінімальний приклад без секретів;
- запропоноване виправлення, якщо воно є.

Для звичайних помилок використовуйте шаблон issue. Результати перевірок поточної реалізації описані в [docs/verification.md](docs/verification.md).
